# Inbox Dashboard (TriageMail)

A fast, calm, and action-oriented email triage dashboard built with Next.js (App Router), TypeScript, and Tailwind CSS, designed to mirror the Stitch design system.

---

## Features

- Action-First Hierarchy
- Priority Border Visuals
- Unified Tab Bar
- URL Tab Persistence
- Dynamic Filter Counts
- Real Sync Status
- Card Enhancements
- Server-Side API Security
- Optimistic UI Updates
- Tab-Specific Empty States
- Responsive & Accessible
- Demo Mode

---

## Getting Started

### 1. Prerequisites
- Node.js 18+
- npm

### 2. Configuration
Copy or update `.env.local`:
```bash
APPS_SCRIPT_URL=your_google_apps_script_web_app_url
API_TOKEN=your_secure_token
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
npm start
```
